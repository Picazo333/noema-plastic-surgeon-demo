# References

These sources are used as **implementation/visual benchmarks**, not as evidence for medical claims.

## Visual / UX benchmark scan
- SMPLY Studio — *Luxury Aesthetic Clinic Website Design*: editorial hierarchy, soft neutral palette, clear consultation CTA.
- Mederi Digital — *Marchetti Aesthetic Surgery*: quiet-confidence positioning, ivory/charcoal palette, physician-led identity.
- Premier Surgical Arts case study — trust-first navigation, accessible consultation flow, restrained interaction.

## Interpretation used in this demo
The project adopts only broad design principles: calm authority, restrained palette, strong hierarchy, explicit trust boundaries and conversion without urgency. It does **not** copy layouts, imagery, copy, clinical claims or proprietary brand assets from reference sites.
