# Brand System — VÉRTICE

## Territory
**Quiet clinical luxury**: physician-led, architectural, calm, precise. More private practice / editorial monograph than med-spa promotion.

## Palette
- Bone paper `#F4EFE7`
- Warm ivory `#FBF8F2`
- Graphite `#181614`
- Oxblood `#6B2431`
- Rosewood `#9B746F`
- Stone `#9E958A`
- Hairline `rgba(24,22,20,.14)`

No cyan. No neon. No saturated tech gradients.

## Type
- Headlines: Georgia / Times-family serif, editorial spacing.
- UI/body: system sans stack for clarity and zero font dependency.
- Numerals: tabular where metrics are shown.

## Shape language
- Thin rules, disciplined radii (mostly 0–24px), strong whitespace.
- Abstract anatomical/profile line art rather than synthetic patient imagery.
- Motion is subtle: opacity/translate only; disabled under reduced-motion preference.

## Voice
- Calm, precise, human.
- Never urgent, discount-led or transformational-hype driven.
- Avoid “perfect”, “guaranteed”, “risk-free”, “instant”, “best surgeon”.
